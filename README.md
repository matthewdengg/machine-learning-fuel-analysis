This project focuses on exploring how molecular structure affects the physical properties of hydrocarbon fuels and biofuels through computational molecular modeling in Avogadro and machine learning analysis using Python, specifically in Google Colab. By compiling and analyzing a dataset of 100 molecules spanning eight chemical families, the created models and visualizations depict how molecular geometry and intermolecular forces determine physical properties such as boiling point, with a Gradient Boosting regression model achieving the strongest predictive performance (R² ≈ 0.93).
